# ORA

A modern, gamified social platform built with Flutter and Supabase.

## Overview

ORA is a mobile-first social platform focused on meaningful connections, communities, identity, and positive social progression. Built by ORACOOL, ORA combines modern messaging and social networking with light gamification and Nigerian-inspired terminology to create a unique social experience that prioritizes authentic relationships over superficial engagement.

The platform emphasizes:
- **Messaging**: Real-time communication with friends and community members
- **Communities**: Connect through Hoods (groups) centered around shared interests
- **Identity**: Express yourself through customizable profiles
- **Progression**: Grow through Aura (reputation) and Steeze (level) systems
- **Entertainment**: Discover and share content through Gbedu (music/entertainment)
- **AI Assistance**: MAI provides intelligent support and enhancements

## Features

### Core Features
- 💬 **Messaging** - Real-time chat and communication
- 🏆 **Aura** - Global reputation and progression score
- 📈 **Steeze** - User level and progression system
- 👥 **Hood** - Groups and communities
- 🎵 **Gbedu** - Music and entertainment section
- 🤖 **MAI** - AI-powered assistance (coming soon)

### Technical Features
- **User Authentication** - Secure login and registration with Supabase Auth
- **Social Feed** - Dynamic content feed with real-time updates
- **Profiles** - Customizable user profiles with identity features
- **Secure Database Access** - Supabase Row Level Security (RLS) for data protection
- **Scalable Architecture** - Modular Flutter architecture designed for growth

## Tech Stack

- **Flutter** - Cross-platform mobile framework
- **Dart** - Programming language
- **Supabase** - Backend-as-a-Service and database
- **PostgreSQL** - Relational database
- **Git** - Version control
- **State Management** - Scalable state management solution
